# Sahana Portfolio

A responsive React portfolio using Vite, with the existing warm dark palette, river-and-egg opening, section navigation, project details and contact form.

## Run locally

1. Open this folder in VS Code.
2. Run `npm install` if dependencies are not installed.
3. Run `npm run dev` and open the local address Vite prints.

Run `npm run build` to create the static hosting bundle in `dist/`.

## Personalize

In `src/App.jsx`, update the `portfolio` object near the top with your real email, resume path, and project/profile URLs. Project focus and technology lists are stored beside each project. The contact form prepares an email in the visitor’s email app; it does not send a message without a configured address or backend.

Update About and intro wording in the React component. Skills are grouped in `skillGroups`. Certification and resume panels are clearly marked placeholders until you add real credentials and a PDF. Add real project screenshots before listing them in the project detail data; current visual thumbnails are CSS illustrations.
